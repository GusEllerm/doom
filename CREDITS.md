## Game content

No id Software assets are shipped with or embedded in this repository.
Runtime content comes from WAD files supplied by the user at run time
and are never committed.

### Freedoom

The default content is [Freedoom](https://freedoom.github.io/), (c) the
Freedoom authors, distributed under the BSD-3-Clause license. Pinning,
checksum and fetch details: `scripts/freedoom/release.json`.

Exact attribution text to be finalized once
`docs/research/12-freedoom.md` records the release's licensing files
(tracked as task R12).

## Derived source

Some constants and behaviors are transcribed from the id Software DOOM
GPL source release and/or Chocolate Doom; files closely adapting them
carry a provenance header (see PROMPT.md §2).
