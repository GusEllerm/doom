## 3. Deviations, deferred hooks, and open decisions

- **D-11a (M11-02) byte-format honesty**: a byte-faithful vanilla `.dsg` needs id’s exact `player_t`/`mobj_t` C memory layouts (struct padding, pointer swizzles) — reconstructing those buys zero observable fidelity in a browser (nothing external reads our files; the header’s ONLY observable surface is the 24B description shown by the menu). Decision: header **byte-faithful** (§0.1 layout exactly, `"version 110"`, 0x1d terminator), payload = OUR structured container (versioned, `DBP1` magic). The mirror files are NOT byte-similar beyond the header — documented, not hidden.
- **D-11b (M11-04/10) persistence NEVER inside gTicker**: A-02 — the capture half runs INSIDE the drain (pure `captureWorld` ⇒ bytes; vanilla does its file write at the same tic-boundary site, §0.3), the IndexedDB write happens async AFTER the tick; loads request `ga_loadgame` and execute in the next drain (vanilla’s own deferral, §0.3). The sim stays sync/pure/deterministic; the “save mid-frame then reload” observable == vanilla timing (same-tic-boundary world state). (Sites: M11-04/M11-10.)
- **D-11c (M11-06) faithful no-checksum**: 1.10 demos carry no desync detection (§0.5) — we add NONE. Determinism is certified test-side by the record→replay hash-identity golden; desyncs are therefore *silent like vanilla* — the e2e never depends on detecting one.
- **D-11d (M11-07) bindings**: 1.10 = no bind menu, config = default.cfg vars (§0.6); the IndexedDB settings store IS the config-file port (write-on-change, browser has no quit). A-09’s WASD table + 1.9-style bind UI stay an extension: defaults + data-model shipped now, UI deferred.
- **D-11e (M11-06) demos**: 1.10 demo I/O is lump-only and the pinned WAD has zero DEMO lumps (§0.5, D023) — our demos are first-class BYTES: recorded `.lmp` = downloadable Blob, playback consumes bytes from `playDemo()` or a loaded file. User-demo attract playback stays Post-M12 stretch (ROADMAP); `-record` has no vanilla key — the debug seam is the affordance (D016-class dev surface).
- **D-11f (M11-09) cheat timing**: vanilla cheats mutate state in the EVENT pump (pre-tic, ST_Responder). We route effects through `hooks.cheatSink` in the same phase (event pump of the tick block). God/noclip toggles landing mid-frame carry no observable hash delta (they gate the NEXT tic); the ledger records the tic of effect.
- **D-11g (M11-01) zone expansion**: ARCHITECTURE’s cross-cut line named one `platform/storage.ts` task; M11 grew a codec + payload + settings + demo-file surface that deserves its own import-boundary zone `src/persist/` (same rules as ui/audio: sim imports nothing from it). ARCHITECTURE §9 A-10 gets a pointer note in M11-12; DECISIONS D008 unchanged.
- **Deferred / registered (counted, none new-console)**: chat sfx + `HU_dequeueChatChar` path (netgame-only, §0.8) → Post-M12; netgame save semantics, `M_EndGame` confirm variants, game-query/endpoint detail rows; bind-menu UI (D-11d); automap mark persistence — vanilla has none (§0.8), so NOTHING to port; demo attract playback of user demos (D023/ROADMAP stretch); `snd_channels`/joystick rows persisted but inert (no joystick in M11); PCX screenshot files (M_ScreenShot) stay a download seam if ever requested.
