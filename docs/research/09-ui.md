## 1. Menu system (m_menu.c / m_menu.h)

### 1.1 Setup arrays (main, skill, episode, options, load/save, quit)

Structures (`m_menu.c`): `menuitem_t { short status; char name[10]; void(*routine)(int);
char alphaKey; }` — status: `0`=no cursor, `1`=ok, `2`=arrows (thermometer), `-1`=empty
spacer; `menu_t { numitems, prevMenu, menuitems, routine(draw), x, y, lastOn }`.
Constants: `SKULLXOFF -32`, `LINEHEIGHT 16`, `SAVESTRINGSIZE 24`, `savegamestrings[10][24]`.

Flow: New Game → (Doom1 non-commercial) `EpiDef` → pick episode sets `epi` → `NewDef` →
`M_ChooseSkill(choice)` → `G_DeferedInitNew(choice, epi+1, 1)`. Commercial mode goes
straight to `NewDef`. In shareware, `M_Episode` on ep≠1 shows `SWSTRING` then jumps to
ReadDef1 (ad screen). `M_Init` rewrites menus by gamemode: commercial removes ReadThis
(`MainMenu[readthis]=MainMenu[quitdoom]; MainDef.numitems--; MainDef.y+=8`), shareware+
registered do `EpiDef.numitems--` (3 episodes; retail has 4).
Save/load draw: title patch `M_LOADG`/`M_SAVEG` at 72,28; border via `M_LSLEFT` + 24×
`M_LSCNTR` (x+=8) + `M_LSRGHT` at `(x-8,y+7)`; slot text with `M_WriteText` (hu_font) at
`LoadDef.x, LoadDef.y+16*i`; blinking `_` cursor while `saveStringEnter`.
F-key shortcuts in `M_Responder`: F1 help, F2 save, F3 load, F4 sound, F5 detail, F6
quicksave, F7 endgame, F8 messages, F9 quickload, F10 quit, F11 gamma, `-`/`=` screen size.
Quick-save: if `quickSaveSlot<0` opens SaveDef with `quickSaveSlot=-2` ("pick a slot now").

### 1.3 Skill menu (wimp message, gameskill enum)

`newgame_e { killthings, toorough, hurtme, violence, nightmare }` → maps 1:1 to
`gameskill_t sk_easy..sk_nightmare` passed as `choice` to `G_DeferedInitNew`.
There is **no "too wimpy" message in the Doom 1.10 source** — grep for `wimp` only hits
`dstrings.c` `endmsg[]` entries `"suck it down, asshole!\nyou're a fucking wimp!"`, which is
a **FinalDOOM (DOOM2) quit taunt**, indexed past `NUM_QUITMESSAGES` (22) and never used by
Doom 1 (Doom1 uses endmsg[0..7] only; `M_QuitDOOM`: `endmsg[(gametic%(NUM_QUITMESSAGES-2))+1]`
in the original arrays — with only 8 compiled in for doom1 the usable set is the 8 DOOM1
strings). Our Doom1 target: 8 taunts, or original text (see §4 IP note).
The only skill-related confirm is Nightmare: `M_ChooseSkill(nightmare)` →
`M_StartMessage(NIGHTMARE, M_VerifyNightmare, true)` with
`NIGHTMARE = "are you sure? this skill level\nisn't even remotely fair.\n\n" PRESSYN`
(d_englsh.h:53).

### 1.4 Episode menu (names, Doom1 count, Freedoom episodes)

Episode *names* are **not strings in the executable** — they are baked into the `M_EPI1..4`
menu graphics (all present in freedoom1.wad). d_englsh.h only holds level names
(`HUSTR_E1M1 "E1M1: Hangar"` … E4M9) used by the HU level ticker. Doom1: retail=4
episodes, registered/shareware=3 (per `M_Init`). Freedoom1.wad ships WILV30–WILV38
intermission art for a 4th episode → treat as 4 episodes (final count to cross-check with
R-pickup/levels doc via MAP xdefs; M_EPI4 graphic exists).

### 1.5 M_Responder: keyboard + mouse hit-test (quoted)

There is **no pixel hit-test**; the mouse is a virtual d-pad (m_menu.c, M_Responder):

```c
if (ev->type == ev_mouse && mousewait < I_GetTime()) {
    mousey += ev->data3;
    if (mousey < lasty-30) { ch = KEY_DOWNARROW; mousewait = I_GetTime() + 5; mousey = lasty -= 30; }
    else if (mousey > lasty+30) { ch = KEY_UPARROW; ... }
    mousex += ev->data2;   // ±30 → LEFT/RIGHTARROW, same 5-tic repeat
    if (ev->data1&1) { ch = KEY_ENTER;   mousewait = I_GetTime() + 15; }
    if (ev->data1&2) { ch = KEY_BACKSPACE; mousewait = I_GetTime() + 15; }
}
```

Keys: arrows move `itemOn` (wrap, skipping `status==-1` spacers); left/right call the
status-2 item's routine with 0/1; Enter calls `routine(itemOn)` + `sfx_pistol`; Esc closes
menus (`M_ClearMenus`), Backspace = prevMenu; any letter selects the item whose `alphaKey`
matches (search forward then wrap). While `messageToPrint`, only `' '`, `'y'`, `'n'`, `'N'`,
Esc pass (case-insensitive 'y' check is in the routine: `if (ch != 'y') return;` — responder
upper-cases? No: it forwards raw ch; routines compare lowercase 'y' — keyboard yields
lowercase). Save-string edit mode captures all chars 32–127 up to
`SAVESTRINGSIZE-1=23` chars / `(24-2)*8` px width. Skull cursor drawn at `x-32,
menu->y-5+itemOn*16`; messages are centered: `y = 100 - StringHeight/2`, each line
`x = 160 - StringWidth/2`, line advance `hu_font[0]->height`, `\n` = +12 in M_WriteText.

Confidence §1: HIGH (read m_menu.c fully; quotes verbatim).
